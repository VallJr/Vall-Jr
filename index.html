🧠 Alur Tahapan Berpikir Komputasional

1. Dekomposisi

  • Modul inventaris: menyimpan produk, stok awal, HPP, dan harga jual.
  • Mesin kasir: memilih produk, jumlah beli, subtotal, pembayaran, dan kembalian.
  • Laporan finansial: menghitung modal awal, keuntungan bersih, dan saldo akhir.
  • Riwayat: mencatat transaksi yang berhasil.
  • Peringatan stok: menandai stok ≤ 5 unit.
  • Validasi produk: mencegah harga jual di bawah HPP.

2. Abstraksi

Data utama yang diperlukan cukup direpresentasikan sebagai:

Produk = {nama, stok, stokAwal, hpp, hargaJual}
Transaksi = {waktu, produk, jumlah, total, keuntungan}

3. Pengenalan Pola

  • Setiap penjualan selalu mengurangi stok.
  • Subtotal selalu = harga jual × jumlah.
  • Keuntungan transaksi = (harga jual − HPP) × jumlah.
  • Jika stok ≤ 5, produk perlu diberi peringatan.
  • Setiap transaksi sukses menambah saldo kas sebesar total pembayaran/penjualan.

4. Algoritma

  1. Masukkan data produk: stok awal, HPP, dan harga jual.
  2. Validasi harga jual ≥ HPP.
  3. Pilih produk dan masukkan jumlah beli.
  4. Hitung subtotal = harga jual × jumlah.
  5. Pastikan jumlah beli tidak melebihi stok.
  6. Masukkan pembayaran tunai dan pastikan pembayaran ≥ subtotal.
  7. Kurangi stok sesuai jumlah yang terjual.
  8. Hitung kembalian dan keuntungan transaksi.
  9. Simpan transaksi ke riwayat.
  10. Perbarui dashboard dan status stok secara otomatis.

Pseudocode

START

INPUT produk, stokAwal, HPP, hargaJual

IF hargaJual < HPP THEN
    TAMPILKAN "Harga jual tidak boleh di bawah HPP"
ELSE
    SIMPAN produk
END IF

PILIH produk
INPUT jumlah

subtotal ← hargaJual × jumlah

IF jumlah > stok THEN
    TAMPILKAN "Stok tidak cukup"
ELSE
    INPUT pembayaran

    IF pembayaran < subtotal THEN
        TAMPILKAN "Uang pembayaran kurang"
    ELSE
        stok ← stok - jumlah
        kembalian ← pembayaran - subtotal
        keuntungan ← (hargaJual - HPP) × jumlah

        SIMPAN transaksi
        UPDATE modal, keuntungan, saldo, stok
        TAMPILKAN kembalian
    END IF
END IF

IF stok ≤ 5 THEN
    TAMPILKAN "STOK MENIPIS"
END IF

END
